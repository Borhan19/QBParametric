# QBParametric

Numerical code accompanying the manuscript

**Finite Quantum Pumps for Phase-Locked Parametric Amplification:
Requirements for Quantum-Battery Work Sources**

Borhan Ahmadi  
International Centre for Theory of Quantum Technologies (ICTQT)  
University of Gdańsk

## Contents

- `src/` — simulation and analysis scripts.
- `notebooks/` — development/analysis notebook.
- `data/` — numerical data used in the seeded-signal analysis.
- `outputs/` — saved production-run logs for the calculations reported in the manuscript and Supplemental Material.

## Numerical environment

The production calculations were performed using Python with QuTiP 5.0.4.

Main dependencies:
- NumPy
- SciPy
- Matplotlib
- QuTiP 5.0.4

Install the required packages with

```bash
pip install -r requirements.txt
